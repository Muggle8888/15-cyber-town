# F-011 话题与记忆弹层设计规格

更新时间：2026-09-22

## 目标

在不扩大现有 640×360 对话面板的前提下，让玩家理解“可以聊什么”和“哪些动作会写入当前 NPC 的长期状态”。弹层复用 F-010 的暖色像素边框、Noto Sans CJK SC 字体与深紫面板，不引入新美术资源。

## 首个视觉门禁

- 入口：底部对话面板中的“话题与记忆”按钮。
- 位置：弹层位于底部对话框上方，并保持当前 NPC 名称、关系标签、历史、输入区和关闭按钮可读。
- 正常状态：标题明确包含当前 NPC；六个动作使用自然中文，不显示 `favorite_cyber_town_topic`、`reply_style` 等内部键。
- 布局：两列紧凑按钮，写入类动作以“记住/回复/忘记”明确表达影响；关闭弹层不关闭对话。
- 首个截图：Nia 对话已打开，弹层显示其专属“霓虹夜市”主题。

用户已通过首个实机截图（2026-09-22）；确认状态、请求锁定、失败与精确重试状态可以进入实现与离线验证。

当前实机产物：[godot-menu-normal-v1.png](godot-menu-normal-v1.png)。截图由 Godot 4.7.2 以项目主场景和 640×360 逻辑视口直接渲染；对应定向城镇测试结果为 `TOWN_TESTS=PASS`。这项证据只证明场景可加载与首个 UI 状态可渲染，不替代用户视觉验收、完整交互验收或真实模型 UAT。

## 固定内容

| NPC | 普通话题草稿 | 记忆值 |
| --- | --- | --- |
| Nia | 今晚的霓虹夜市有什么值得看的？ | 霓虹夜市 |
| Ivo | 信号档案里有什么小镇故事？ | 小镇故事 |
| Rhea | 雨夜街道会影响投递吗？ | 雨夜街道 |

菜单动作：聊聊主题、记住主题、询问是否记得、简洁回复、自然回复、忘记主题。

## 交互规则

- “聊聊主题”和“询问是否记得”只填入输入框，不立即发送。
- “记住主题”“简洁回复”“自然回复”“忘记主题”必须进入确认状态；确认文案明确 NPC、动作和内容。
- 请求期间整个弹层、关闭对话、NPC 切换和重复提交均不可操作。
- 关系标签显示“获取中”或“暂不可用”，只有成功读取后才显示阶段。
