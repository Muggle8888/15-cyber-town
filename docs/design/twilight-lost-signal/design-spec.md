# F-013 暮光失联信号：视觉与交互规格

更新时间：2026-09-22

状态：`VISUAL_APPROVED`

## 设计目的

事件追踪卡应让第一次进入城镇的玩家立即知道“现在可以做什么、下一步去找谁”，但不能遮挡现有连接状态、街区标题、角色或主要道路。它只呈现 Godot 确定性事件状态，不展示模型推理或隐藏规则。

## 首个正常状态

- 逻辑视口：640×360，整数倍缩放。
- 场景：玩家位于入口区域，Nia、暮光导览牌和道路仍清楚可见。
- 位置：视口右上角，避开左侧连接状态与中间街区标题。
- 信息顺序：`街区事件 · 1/7` → `暮光失联信号` → 当前目标 `和 Nia 聊聊今晚异常的灯光`。
- 操作：右上角提供折叠按钮；展开状态不抢占移动与交互键盘焦点。

## 视觉规则

- 复用现有 Noto Sans CJK SC、深紫半透明面板、暖橙标题和像素边框。
- 事件强调色使用暖金色，与青绿色观察卡和橙色对话面板区分。
- 面板宽度不超过 218 像素，高度不超过 76 像素；正文在 640×360 下完整显示。
- 不新增图标、美术、字体或音频资源。
- 打开底部对话面板时，完整实现会自动折叠追踪卡；Step 0 截图只验证展开正常状态。
