# Product Brief — Cyber Town

## 定位

L 级综合 Agent 学习项目：通过一个可运行的 2D AI NPC 小镇，学习角色型 Agent、隔离状态与记忆、确定性业务规则、可观测性、评估、外部模型失败处理与安全防护。

## 目标用户与核心价值

- 主要用户：正在学习 Agent 工程、希望把 LLM 行为落到可测试应用的开发者。
- 次要用户：体验 AI NPC 自然对话、关系变化与可解释反馈的试玩者。
- 核心价值：一个可观测、可复现的玩家—NPC 闭环，而非只展示模型生成文本。

## 首要用户流程

玩家进入最小 Godot 场景 → 接近一个 NPC → 输入一句话 → Godot 调用 FastAPI → 后端构造受预算约束的上下文并调用 LLM → 校验响应、保存审计轨迹与状态 → NPC 在 UI 中回复；失败时玩家获得明确、可恢复的提示。

## 范围

1. 角色 Persona、单 NPC 起步、多 NPC 的身份/状态/记忆隔离。
2. 三元 scope 短期记忆、双元 scope 结构化长期事实、召回/冲突/遗忘与上下文预算。
3. 由确定性规则控制的关系和好感度，LLM 仅提供受校验的分类建议。
4. FastAPI API、SQLite 状态、Godot HTTP 交互、审计轨迹与评估。
5. 超时、重试、降级、内容安全与 prompt-injection 防护。

## 非目标

- 当前产品不包含生产部署、多人在线、开放世界、正式任务系统、语音、大规模原创美术或账号体系；基础可玩版本使用许可明确且风格统一的像素素材、中文字体和提示音。
- 不实现 NPC 间自治协作、批量生成、任意工具调用、向量数据库、SSE/WebSocket 或模型主动修改世界状态；只有出现明确需求和独立评估证据后才重新立项。
- 不把 LLM 作为权限、持久化写入、关系分值、预算、状态转移或安全策略的最终裁决者。

## 成功标准

- 一个玩家与当前所选固定 NPC 的端到端对话可在 Godot + FastAPI 环境完成，三名 NPC 的接口、身份和数据契约一致。
- Persona 一致性、记忆正确率、安全拒答、失败降级、p95 延迟和单轮成本均有可复现实验或人工评估证据。
- NPC 间不存在会话、关系或记忆串扰；每一轮可关联 `trace_id`，日志默认脱敏。
- 每项能力以任务卡、自动测试和人工步骤验证，而不是以“能回复”作为完成标准。
